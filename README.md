# Bulls and Cows CLI Game

A feature-rich, command-line implementation of the classic **Bulls and Cows** code-breaking game written in modern Python. The game challenges players to crack a secret code generated by the computer using numerical feedback after each attempt.

---

## Features

- **Dynamic Difficulty Levels:**
  - **Easy:** 3-digit target number
  - **Standard:** 4-digit target number
  - **Hardcore:** 5-digit target number
- **Robust Input Validation:** Strictly enforces digit length, numerical input, and digit uniqueness.
- **Move History Tracking:** Option to toggle visible history of previous guesses and their respective scores during gameplay.
- **Surrender Mechanics:** Prompts every 5 turns allowing players to reveal the secret code or keep playing.
- **Type Hinting & Modern Syntax:** Fully utilizes Python 3.10+ features including `match-case` statements and modern structural type hints.

---

## Game Rules

The computer selects a secret number with unique digits based on your chosen difficulty level. On every turn, you enter a guess with unique digits of matching length.

You receive scoring feedback in two values:
* **🐂 Bulls:** Correct digits in the **correct** position.
* **🐄 Cows:** Correct digits in the **wrong** position.

### Example
If the secret number is **`3914`** and your guess is **`1954`**:
* **2 Bulls:** Digits `9` and `4` are in the correct positions.
* **1 Cow:** Digit `1` exists in the secret number, but is in the wrong position.

You win when you get **4 Bulls** (or matching digits for your selected difficulty).
